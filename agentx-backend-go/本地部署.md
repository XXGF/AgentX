## 第二步：安装并配置 PostgreSQL

### 2.1 安装 PostgreSQL

```bash
# 安装 PostgreSQL 15（推荐）
brew install postgresql@15

# 启动 PostgreSQL 服务
brew services start postgresql@15

# 将 PostgreSQL 添加到 PATH（如果 brew 未自动添加）
echo 'export PATH="/opt/homebrew/opt/postgresql@15/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### 2.2 安装 pgvector 扩展

项目使用 pgvector 进行向量存储（RAG 知识库功能），**必须安装**。

```bash
# 方式一：通过 Homebrew 安装（推荐）
brew install pgvector

# 方式二：从源码编译安装
cd /tmp
git clone --branch v0.7.0 https://github.com/pgvector/pgvector.git
cd pgvector
make
make install
```

### 2.3 创建数据库用户和数据库

```bash
# 进入 PostgreSQL 命令行
psql postgres

# 在 psql 中执行以下命令：
CREATE USER postgres WITH PASSWORD 'postgres' SUPERUSER;
CREATE DATABASE agentx OWNER postgres;
\q
```

> **说明**：默认配置使用 `postgres/postgres` 作为用户名密码，`agentx` 作为数据库名。如需修改，请同步更新 `configs/config.yaml` 中的 `database` 配置。

### 2.4 验证数据库连接

```bash
psql -h localhost -U postgres -d agentx -c "SELECT version();"
```

如果提示输入密码，输入 `postgres`，看到 PostgreSQL 版本信息即表示连接成功。

## 第五步：配置项目

### 5.1 配置文件位置

项目配置文件位于 `agentx-backend-go/configs/config.yaml`，支持三种配置方式（优先级从高到低）：

1. **环境变量**（推荐生产环境使用）
2. **配置文件** `configs/config.yaml`
3. **代码默认值**

### 5.2 最小配置（仅需数据库即可启动）

默认配置已经可以直接使用，只需确保 PostgreSQL 按上述步骤配置完成即可。

`configs/config.yaml` 中的关键默认值：

```yaml
server:
  port: 8088              # 服务端口
  context-path: /api      # API 路径前缀

database:
  host: localhost          # 数据库地址
  port: 5432              # 数据库端口
  user: postgres          # 数据库用户
  password: postgres      # 数据库密码
  name: agentx            # 数据库名
  sslmode: disable        # SSL 模式

jwt:
  secret: "5367566B59703373367639792F423F4528482B4D6251655468576D5A71347437"
  expiration: 86400       # Token 有效期 24 小时

logging:
  level: debug            # 日志级别
```

### 5.3 如需修改数据库配置

如果你的 PostgreSQL 使用了不同的用户名/密码/端口，修改 `configs/config.yaml` 中的 `database` 部分：

```yaml
database:
  host: localhost
  port: 5432
  user: your_username      # 修改为你的用户名
  password: your_password  # 修改为你的密码
  name: agentx
  sslmode: disable
```

或者通过环境变量覆盖（无需修改配置文件）：

```bash
export DB_HOST=localhost
export DB_PORT=5432
export DB_USER=your_username
export DB_PASSWORD=your_password
export DB_NAME=agentx
```

## 可选服务配置

以下服务为可选配置，不配置不影响核心功能启动，但会影响对应功能的使用。

### 📧 邮件服务（SMTP）

用于发送注册验证码、重置密码等邮件。**未配置时验证码仅打印到日志**。

```yaml
# configs/config.yaml
mail:
  smtp:
    host: smtp.qq.com        # QQ邮箱: smtp.qq.com / 163: smtp.163.com / Gmail: smtp.gmail.com
    port: 587                # 587=STARTTLS / 465=SSL
    username: "your-email@qq.com"
    password: "your-smtp-auth-code"  # QQ邮箱需在设置中生成授权码
```

**QQ 邮箱获取授权码步骤**：
1. 登录 QQ 邮箱 → 设置 → 账户
2. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
3. 开启「IMAP/SMTP服务」
4. 按提示发送短信获取授权码

## 常见问题排查

### Q1: 数据库连接失败

```
连接数据库失败: dial tcp [::1]:5432: connect: connection refused
```

**解决方案**：

```bash
# 检查 PostgreSQL 是否运行
brew services list | grep postgresql

# 启动 PostgreSQL
brew services start postgresql@15

# 检查端口是否被占用
lsof -i :5432
```

### Q2: pgvector 扩展不存在

```
ERROR: could not open extension control file "/opt/homebrew/share/postgresql@15/extension/vector.control"
```

**解决方案**：

```bash
# 重新安装 pgvector
brew install pgvector

# 或从源码编译
cd /tmp && git clone https://github.com/pgvector/pgvector.git
cd pgvector && make && make install

# 然后在数据库中启用
psql -h localhost -U postgres -d agentx -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### Q3: Go 版本不兼容

```
go: go.mod requires go >= 1.18
```

**解决方案**：

```bash
# 检查当前版本
go version

# 升级 Go
brew upgrade go
# 或使用 GVM 切换版本
gvm install go1.18
gvm use go1.18
```

### Q4: 端口 8088 被占用

```
listen tcp :8088: bind: address already in use
```

**解决方案**：

```bash
# 查找占用端口的进程
lsof -i :8088

# 杀掉进程
kill -9 <PID>

# 或修改配置使用其他端口
# configs/config.yaml → server.port: 9090
# 或 export SERVER_PORT=9090
```

### Q5: 邮件发送失败

```
SMTP认证失败: 535 Login Fail
```

**解决方案**：
- 确认使用的是 SMTP **授权码**而非邮箱登录密码
- QQ 邮箱需要在设置中开启 IMAP/SMTP 服务并生成授权码
- 检查 SMTP 端口是否正确（QQ: 587 或 465）

### Q6: Docker 连接失败

```
Docker daemon 连接失败，容器功能将不可用
```

**解决方案**：
- 确认 Docker Desktop 已启动
- 检查 Docker socket 路径：`ls -la /var/run/docker.sock`
- 这是一个警告，不影响其他功能正常使用

### 快速启动脚本

将以下内容保存为 `start.sh`，一键完成本地启动：

```bash
#!/bin/bash
set -e

echo "🚀 AgentX Go 后端本地启动脚本"
echo "================================"

# 检查 Go 环境
if ! command -v go &> /dev/null; then
    echo "❌ 未找到 Go 环境，请先安装 Go 1.18+"
    exit 1
fi
echo "✅ Go 版本: $(go version)"

# 检查 PostgreSQL
if ! pg_isready -h localhost -p 5432 &> /dev/null; then
    echo "❌ PostgreSQL 未运行，尝试启动..."
    brew services start postgresql@15 2>/dev/null || true
    sleep 3
    if ! pg_isready -h localhost -p 5432 &> /dev/null; then
        echo "❌ PostgreSQL 启动失败，请手动检查"
        exit 1
    fi
fi
echo "✅ PostgreSQL 运行中"

# 检查数据库是否存在
if ! psql -h localhost -U postgres -d agentx -c "SELECT 1" &> /dev/null 2>&1; then
    echo "📦 创建数据库 agentx..."
    createdb -h localhost -U postgres agentx 2>/dev/null || true
    echo "📦 初始化数据库表..."
    psql -h localhost -U postgres -d agentx -f ../docs/sql/01_init.sql
fi
echo "✅ 数据库 agentx 就绪"

# 下载依赖
echo "📦 下载 Go 依赖..."
go mod download

# 启动服务
echo "🚀 启动 AgentX 后端服务..."
echo "   访问地址: http://localhost:8088/api/health"
echo "================================"
go run ./cmd/server/
```

```bash
# 赋予执行权限并运行
chmod +x start.sh
./start.sh
```
